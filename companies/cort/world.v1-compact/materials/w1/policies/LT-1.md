LT-1 — fixed residential extension tariff
Effective September 1, 2026. USD, pre-tax.

L310 monthly item rates: S1 sofa $60; B1 queen bed $90; D1 dresser $30. Existing charges cover all three through September 14 inclusive. Extension days begin September 15 and run through each item's actual pickup date, inclusive, at monthly rate divided by 30 per calendar day.

One final pickup is included. Voluntarily splitting the originally included pickup adds one $25 visit charge. If an item cannot be collected because it has not been emptied, its rent continues through actual collection. One recovery attempt is included without an additional visit charge.

Every quotation must explain that actual pickup dates control retained-day charges. No unlisted concessions, rate changes or tax calculations are authorized in this pre-tax handoff. L310 has no cancellation or early-return penalty.

Accepted changes must reference exact offer versions and item dates. Lease instructions must include expected version, acceptance reference, item rates, dates, visit structure and superseded instructions. Billing instructions must reconcile those terms with actual collection evidence, not merely booked dates.
