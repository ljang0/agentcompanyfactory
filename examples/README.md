# Examples

## Cedarline Apparel Supply (SanMar)

[Open the example](sanmar/README.md) for a four-worker apparel supply company,
eight native apps and two accepted tasks. The index links public assignments,
private benchmark author materials, calibrated verifiers, trial grades and provenance.

The full operating world and desktop outputs are attached to the upstream
[inspection release](https://github.com/ljang0/agentcompanyfactory/releases/tag/sanmar-inspection-2026-09-14).
This Git selection is intentionally small enough to browse. See the example's
measured limits before using it as a benchmark.

## Add an example

Include a short explanation, the public assignment, relevant results and a mapping
to the exact source snapshot. Keep large recordings and native state in a release
archive with checksums. Identify references, assessments and graders as benchmark
author materials, separate from the files a worker may receive.
